# 📊 Proyecto de Análisis Logístico y Financiero con PostgreSQL y Python

## 🎯 Descripción del Proyecto
Este proyecto simula un entorno real de análisis de datos para una empresa de distribución y logística. Su objetivo principal es integrar fuentes de datos relacionales con herramientas de análisis moderno para extraer insights financieros, evaluar el rendimiento de ventas por categoría y medir los niveles de servicio (estado de las entregas).

## 🛠️ Stack Tecnológico Utilizado
- **Base de Datos:** PostgreSQL (Modelado relacional de tablas: `productos`, `clientes`, `ventas`).
- **Extracción y Conexión:** Python, Pandas, SQLAlchemy, Psycopg2.
- **Entorno de Desarrollo:** Jupyter Notebook, Anaconda.

## 📈 Principales Hallazgos y Métricas
- **Ingresos Totales:** $11,310,000.00
- **Ganancias Totales:** $4,420,000.00
- **Rendimiento por Categoría:** La categoría *Alimentos* lidera el volumen de ventas y margen de ganancia.
- **Logística y Entregas:** Se identificaron cuellos de botella operativos con un porcentaje de entregas retrasadas y en tránsito que requieren optimización de rutas.

## 🚀 Cómo Ejecutar el Proyecto
1. Clonar el repositorio.
2. Configurar la base de datos localmente en PostgreSQL ejecutando los scripts SQL de creación de tablas.
3. Abrir el archivo de Jupyter Notebook (`.ipynb`) y ajustar las credenciales de conexión en la celda inicial.
4. Ejecutar las celdas secuencialmente.
